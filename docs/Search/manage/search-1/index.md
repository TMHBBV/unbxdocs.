# Overview

The **Manage** section in the Netcore Unbxd Console helps you optimize how search results are presented to shoppers by configuring both **Searchable Fields** and **Facets**. These tools ensure your catalog data is aligned with shopper behavior, increasing product discoverability, relevance, and conversion rates.

***

# Searchable Fields

Use **Searchable Fields** to determine which product catalog fields influence search relevance and how much weight each field carries.

### Key Capabilities:

* Enable or disable catalog fields for search.
* Assign **Search Weights** as `High`, `Normal`, `Low`, or `Non-Searchable`.
* Apply **AI-recommended weights** based on catalog and query analysis.
* Preview **product coverage** and **query coverage** for each field.

This is essential for ensuring search results match user expectations based on critical fields like title, brand, and SKU.

***

# Facets

Facets help shoppers refine their search results using product attributes like brand, price, material, or ratings.

### Key Capabilities:

* Set global filtering rules using the **All Queries** rule.
* Create **Field-Based Facets** that dynamically apply when 80%+ of results meet specific conditions.
* Configure display properties such as facet title, length, and sort order.
* View, edit, publish, and manage all facet campaigns from a single dashboard.
* Support bulk upload and download of facet configurations.

Facets streamline navigation on product listing pages (PLPs) and guide shoppers toward the right products faster.

***

# When to Use What?

| Feature               | Use It For                                                           |
| --------------------- | -------------------------------------------------------------------- |
| **Searchable Fields** | To determine which fields should contribute to search relevance.     |
| **Facets**            | To control which filters appear on the product listing page and how. |

***

Configure both settings thoughtfully to deliver a smarter, faster, and more relevant search and browse experience to your customers.
