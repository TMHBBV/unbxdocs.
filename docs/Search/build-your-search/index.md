# Overview

Unbxd offers a powerful, platform-agnostic site search engine designed to provide highly relevant search results, increase engagement, and optimize the user experience for the end users. Integrate and manage site search features, including feed preparation, analytics setup, and deploying **Unbxd** **Search**.

# Prerequisites

Before you begin integrating **Unbxd Search** into your site, the following requirements must be met:

1. **Create an Unbxd Account**\
   You must first create an Unbxd account to access the required API keys. Once you have created your account, you can find these keys by navigating to the following path within your Unbxd Console:
   **Manage** > **Configure Site** > **Keys**
2. **Obtain API Keys**\
   Ensure you have all necessary API keys for integration. These will be used to authenticate and configure the Unbxd services for your site.
