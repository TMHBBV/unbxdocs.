# Overview

To integrate Unbxd search, follow these three key steps:

1. **Feed Preparation and Upload**\
   Prepare your product catalog in a format compatible with Unbxd. Once prepared, you can upload it to the Unbxd platform via:

* Direct Feed Upload
* Feed APIs

> 📘 Resources
>
> [Direct Feed Upload Guide]()
>
> [Feed API Documentation]()

2. **Set up Analytics**\
   Once your catalog is uploaded, you need to integrate analytics. This allows **Unbxd** to collect data and optimize search results. You can integrate analytics via:
   * Analytics API
   * Browser Integration
   * Google Tag Manager

> 📘 Resources
>
> [Analytics API Integration Guide]()
>
> [Browser Integration Guide]()

3. **Deploy Unbxd Search**\
   The final step is to deploy Unbxd search, which will start delivering optimized search results for your site. Unbxd provides several options for integration:
   * RESTful APIs for Search & Autosuggest: Use these to integrate **Search** and **Suggest** functionality.
   * SDKs for Search: Unbxd provides SDKs for integration with Android, iOS, and JavaScript-based sites.
   * Platform Plugins: Pre-built plugins are available for Magento, Shopify, and Hybris stores.
