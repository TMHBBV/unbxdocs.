Before you can integrate our SDK, you need to:

STEP 1: Set up your Site Search Dashboard

STEP 2: Get your API key and Site key

STEP 3: Upload your Product Feed

You need to have a:

* Kotlin 1.2.71 or above
* Okhttp3 3.8.1 or above

Our SDK is `.arr `programmed using Kotlin. This can be integrated with the Android application programmed with either Kotlin or Java.
