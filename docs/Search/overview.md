# Overview

The **Overview** dashboard provides a snapshot of your e-Commerce site's search performance. It offers real-time insights into user interactions, search effectiveness, and revenue contributions, enabling data-driven decisions to enhance user experience and drive conversions.

# Key Metrics

At the top of the dashboard, you find high-level metrics that provide a quick glance at your site's search performance:

* **Visits**: Total number of sessions where users interacted with the search feature.
* **Hits**: Total number of search queries executed.
* **Click Through**: Number of times users clicked on search results.
* **Cart Through**: Number of times products were added to the cart from search results.
* **Sale Through**: Number of purchases completed after using search.

These metrics help in understanding user engagement and the effectiveness of the search functionality.

***

# Revenue Analytics

The **Commerce Search Revenue** graph displays the revenue generated through search interactions over the past two weeks.

* **Total Revenue**: Aggregate revenue from search-driven purchases.
* **Revenue per Visit**: Average revenue generated per search session.
* **Revenue per Hit**: Average revenue generated per search query.

***

# Search Engagement Trends

The **Commerce Search Visit & Query Report** graph illustrates user engagement with the search functionality over the past two weeks:

* **Search Visits**: Number of sessions where users utilized the search feature.
* **Search Queries**: Total number of search queries made.

Analyzing these trends helps in identifying patterns and potential areas for improvement in search engagement.

***

# Catalog Status

Located at the top-right corner, this section provides information about your product catalog:

* **Total Number of Products**: Count of products currently indexed and available for search.
* **Last Catalog Upload**: Timestamp of the most recent catalog update.
* **Last Indexing Status**: Current status of the product indexing process (e.g., INDEXED, PROCESSING, FAILED).

Regular monitoring ensures that your product data is up-to-date and accurately reflected in search results.

***

> 📘 Best Practices
>
> * **Regular Monitoring**: Frequently check the dashboard to stay updated on search performance and catalog status.
> * **Analyze Trends**: Use the graphs to identify patterns in user behavior and revenue generation.
> * **Address Issues Promptly**: Respond to notifications and alerts to maintain optimal search functionality.
> * **Optimize Search Features**: Based on insights, refine search configurations, such as synonyms and facets, to enhance user experience.
