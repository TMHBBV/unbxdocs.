Autosuggest Features\
Autosuggestion feature provides query suggestions that appear when shoppers start typing their intended query in the search bar. Having query suggestions enhances shopper’s search experience once by:

Reducing the efforts/clicks to discover a product\
Reducing typos in search queries by autocompleting misspelled ones
Finding related product options for the same query
Autosuggestions plays an active role in determining what shoppers will search for and how they discover products on your websites, it’s important to set it up properly. Our autosuggest feature provides query suggestions that are relevant to the shoppers’ query.

Autosuggestions are a combination of autocompletion and relevancy which means that not only that autosuggest provides relevant results but also correct the misspelled ones and deliver results. Unbxd’s autosuggest product allows our customers to power a diverse set of experiences on their website.

Some salient features of our autosuggest product are listed below.

Features\
Ranking Suggestions

Our autosuggest algorithms use relevance and user-interaction data to dynamically rank the query suggestions with relevant results. Query suggestions performing poorly are automatically pushed lower and the query suggestions performing well are always ranked higher.

Variety of Suggestions

Our autosuggest provides six types of query suggestions viz Keyword Suggestions, In-Field Suggestions, Top Queries, Popular Products, Trending Queries, and Promoted Suggestions. You can use a combination of these suggestion types to help your shoppers discover products faster.

Engagement Insights

The relevance and performance of auto-suggest query suggestions can be tracked using the “Typeahead” reports section. The performance of each type of query suggestion can be tracked from these reports.
