# A

## Analytics API

Provides data on user interactions, search trends, click-through rates, and conversion metrics for analysis and decision-making.

## Android SDK

A development kit to integrate Unbxd's features into Android mobile applications.

## Attribute Enrichment

Enhancing product catalog data by adding or refining attributes to improve search relevance and merchandising options.

## Autosuggest

A feature that shows predictive search suggestions as the user types, improving speed and engagement.

## Catalog Management

The process of uploading, organizing, and maintaining a structured and accurate product catalog.

# F

## Facets

Also called filters—these allow users to narrow search results based on product attributes like size, brand, or price.

## Feed

A structured data file containing your entire product inventory, typically formatted in XML, CSV, or JSON.

# I

## iOS SDK

A software kit for adding Unbxd’s functionalities into iOS applications.

## Intent Detection

AI-powered feature that interprets the meaning behind user search queries to improve result relevance.

# M

## Magento Integration

A connector to seamlessly integrate Unbxd into Magento-powered e-commerce sites.

# N

## Named Entity Recognition (NER)

Identifies key terms in user queries—like brand names or product categories—to refine results.

## Netcore Unbxd

An AI-powered e-commerce discovery platform for search, navigation, recommendations, and personalization.

# P

## Product Card Mapping

Configuration for how product details are displayed (e.g., title, price, image) in search or listing views.

# R

## Ranking

The order in which products appear in search results, typically based on relevance, business rules, or performance metrics.

## Reports

Summarized views of data like search trends, usage behavior, and conversions for business analysis.

# S

## Schema

The blueprint or structure for your catalog—defining fields like title, price, image\_url, etc.

## Search API

An endpoint to integrate intelligent search capabilities into your website or app.

## Shopify Integration

An out-of-the-box integration for adding Unbxd services to Shopify-based stores.

## Stemming

A search technique that reduces words to their root form, ensuring broader matches (e.g., “running” → “run”).

## Synonyms

Alternative words treated as equivalent in searches to improve query matching (e.g., “laptop” = “notebook”).

# V

## Visual Search

A feature that allows users to search using an image instead of keywords.
