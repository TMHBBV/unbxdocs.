Manage the behavior and visibility of catalog fields across different modules within your product feed. Users can view, edit, and perform bulk operations on field properties to ensure that the catalog data is optimized.

Whether you are setting up a new feed or editing an existing configuration, this page allows you to fine-tune your catalog’s structure.

| Header           | Description                                                                                                                                                                                                                                                                                                                                                                                              |
| ---------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Field Names**  | The list of fields available in the product catalog. Each field includes the field name and its data type such as text, number, and so on.                                                                                                                                                                                                                                                               |
| **Multi-Valued** | Indicates whether a field can have multiple values such as, product with multiple colors. Values can be either `true` or `false`.                                                                                                                                                                                                                                                                        |
| **Features**     | Shows the feature tags enabled for the field. Features could include: \<br>• **Merchandisable** – Field is available in merchandising modules. \<br>• **Facetable** – Field can be used in facets and banners. \<br>• **Searchable** – Used for indexing and search. \<br>• **Autosuggest** – Used for keyword/infield suggestions. \<br>• **Field Rule** – Enables rule-based control using this field. |

***

## Functionalities

| Icon/Button      | Functionality                                                                                                                                                                                                                                                  |
| ---------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Search**       | Use this to search catalog fields by name.                                                                                                                                                                                                                     |
| **Refresh**      | Refreshes the field list to fetch the most updated version from the catalog.                                                                                                                                                                                   |
| **Filter**       | Apply filters to narrow down fields.                                                                                                                                                                                                                           |
| **More Options** | Opens a dropdown with options for: \<br>• **Bulk Upload Field Properties** – Upload a CSV or structured file to configure field properties in bulk. \<br>• **Bulk Download Field Properties** – Download current field settings for review or offline editing. |
| **Sync**         | If you have made any changes to any of the fields features. CLick Re-sync to refresh the feed.                                                                                                                                                                 |
| **Actions**      | Provides bulk operation options: \<br>• **Bulk Enable Features**- Turn on properties for multiple fields in one action. \<br>• **Bulk Disable Features** – Turn off properties in bulk.                                                                        |
| **Edit**         | Opens an edit dialog for individual field property configuration. Allows enabling/disabling features or modifying attributes.                                                                                                                                  |
