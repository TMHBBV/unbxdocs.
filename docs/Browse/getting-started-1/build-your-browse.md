# Pre-requisites

Before you start integrating Browse, you must create an Unbxd account and get the API Keys required to complete the integration. Once you’ve created your Unbxd account, you can get all the keys in Manage > Configure Site > Keys within your Unbxd Console.

# Website URL

Enter the URL of the e-commerce site/app you want to integrate the Unbxd Browse. This will add a site on the console and link your site/app. You can also add more sites from the console’s interface.

# Region

This indicates the physical location of the Unbxd servers (Singapore and US). To get the best response, choose the option closest to your server. For example, if you are based in the Asia Pacific (APAC) region, choose Singapore; otherwise, select the US.

# Direct Integration

Unbxd offers a platform-agnostic integration for your eCommerce site search. You can integrate the Unbxd browse by completing the following three steps :

### 1. Feed Preperation and Upload

Following resources can guide you for converting your catalog to Unbxd compatible format and uploading it on Unbxd systems:

* Direct Feed Upload
* Feed APIs

### 2. Set up Analytics

Once you upload your catalog, the next step is to integrate analytics so that Unbxd systems can collect data to optimize your site search performance. You can integrate Unbxd analytics using one of the following methods:

* Analytics API
* Browser Integration
* Google Tag Manager

### 3. Deploy Unbxd Browse

The final step in the process of integration is to use Unbxd search to display search results for shopper’s queries. Unbxd offer RESTful APIs & SDKs for different platforms to allows easy implementation of our Search

* REST APIs for Browse:
  * Browse API
  * PDP API
* SDKs for Search integration :
  * Android SDK
  * iOS SDK
  * JavaScript SDK
* Platform plugins for Feed & Analytics integration: E-commerce stores using Magento 2 (and higher) Shopify, Hybris platforms can use our pre-built plugins to integrate Unbxd search and browse quickly. The platform plugins support the seamless transfer of catalog and analytics data from your e-commerce store. Select the platform you are using to learn about integration steps :
  * Magento
  * Shopify
  * Hybris
  > 📘 NOTE
  >
  > Platform plugins only support catalog & analytics data transfer. Step 3 to deploy search must be carried out in plugin based integrations too.

### Segmentation

After uploading the catalog and integrating analytics, you can configure Unbxd Browse in your site. You can further choose to integrate via creating:

* Segments
* Merchandise your Catalog: The Merchandising section of the console provides useful controls that will help you merchandise products in your inventory. With merchandising you can:

1. Promote popular products to increase revenue ratios
2. Create slots of similar categories of products to rank higher on the display page
3. Configure dynamic facets
4. Create specific landing-pages for festivals and occasions
5. Arrange filters to narrow-down results
6. With such merchandising methods, shoppers are sure to get their quick and intended products.

Use the following resources to learn more about merchandising:

1. Create rules to boost products across the site
2. Merchandise a Page
