# Overview

**Collections** in UNBXD allow merchandisers to group and manage a curated list of products. These product sets are commonly used for **thematic campaigns**, **seasonal landing pages**, or **merchandising showcases** (e.g., *“Leather Handbags”*, *“Summersale Cotton Products”*). Collections can be enriched using custom attributes and are automatically saved under `collection_unx` for backend management.

***

# Collections Dashboard Overview

This is the landing view of the **Collections** module. It provides a snapshot of all created collections and their campaign usage.

| Column                   | Description                                                                            |
| ------------------------ | -------------------------------------------------------------------------------------- |
| **Collection Details**   | Name of the collection, creation date/time, and live status tag.                       |
| **No. of Products**      | Total number of products currently assigned to the collection.                         |
| **Associated Campaigns** | Shows how many **Search** or **Browse** campaigns are using this collection.           |
| **Actions**              | You can **Edit**, **Download**, or **Delete** the collection using icons on the right. |

### Example Collections:

* `Leather Handbags` – 29 products
* `dresses` – 2880 products
* `Summersale_Cotton Products` – 10 products\
  All are currently marked **Live**.

***

## Add a Collection

1. Click **Add Collection**.
2. Name the Collection.
3. Add Products. You can search by product ID or name.
4. Apply Filters – Use attribute-based filters to find and add products (e.g., category = handbags).
5. Assign Custom Attributes (optional)
6. **Save** the collection.

> 🔁 After editing collections or uploading new ones, use the **“Sync”** button to refresh the display and push updates across active campaigns.

***

# Filters

The dashboard includes filtering tools to narrow down the list of collections shown:

* **Search** by collection name.
* **Filter** based on status, creation date, or usage in campaigns.
* **Sync** to update data and reflect backend changes instantly.
