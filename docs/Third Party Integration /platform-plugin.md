# Overview

A platform plugin is a software component that seamlessly integrates two systems (in this case, your eCommerce platform and a service like Netcore Unbxd). It acts as a bridge, enabling data to flow between the systems without manually uploading or configuring data every time. Essentially, a plugin simplifies connecting your eCommerce platform (such as Magento or SAP Hybris) with Netcore Unbxd for tasks like uploading product catalogs, syncing data, or applying transformations.

### Key Points About Platform Plugins:

1. **Seamless Integration**: A platform plugin integrates with the eCommerce platform directly, reducing manual work for the user.
2. **Automated Data Sync**: The plugin automatically syncs product data (catalogs, images, descriptions) between the eCommerce platform and the external service (like Unbxd), ensuring that your data is up to date without extra work.
3. **Simple Uploads**: Instead of manually uploading data via SFTP, URL, or computer, the plugin enables a simpler way to upload feeds directly from your eCommerce platform.
